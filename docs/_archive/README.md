# Documentos archivados

Documentos retirados del flujo activo pero conservados por su valor histórico.
**No reflejan el estado actual del proyecto.** No los uses como fuente de
verdad para versión, arquitectura o comportamiento runtime.

## Inventario

- `VANDITS-v2.0-DOCUMENTATION.md` — Documento aspiracional v2.0 originado en
  fases tempranas. Fue causa frecuente de despistes para agentes externos

  como "v2.0". Archivado el 2026-05-24 en el PR de versioning hardening
  (v1.4.5). Fuente única de verdad de versión: `src/lib/app-version.ts`.
